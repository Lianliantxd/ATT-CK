# 实际Episode协议

固定本地Ollama 0.35.1，deepseek-r1:1.5b，digest `a42b25d8c10a841bd24724309898ae851466696a7d7f3a0a408b895538ccbc96`，Q4_K_M、1.777B参数。CPU两线程、num_gpu=0、并发1、temperature=0、seed=42、context8192、单次最大输出512。无外部模型调用。

先在已暴露step0完成最小真实Episode，再执行元数据预选12例×4方法。A0为无额外日志的Direct，仍共享相同Top20部分公开知识；A1为初始词频驱动BM25检索；A2两次固定关键词查询；A3由同一模型选择只读工具。所有方法共用初始256 regex代理日志、216父技术候选、K2 16.1、同一步合法日志池。不是“无知识Direct”与“有知识Agent”的比较。

新增证据上限同时满足2048重建GGUF BPE tokens、2048 regex代理、20条新事件和2次查询；公开知识检索消耗相同查询额度。完整模型输入另计控制消息和工具封装，不等于新增证据Token。所有调用实际API输入/输出另记。未返回的合法池内容不得交给模型。禁止读取Gold、其他步骤、受限PwnKit场景1步骤35–37及任何别名副本；工具无shell/write/network权限。

最终要求10个不同且合法的父技术ID、可见event_id引用及局限。重复ID不去重补齐，不重试修复，计输出契约失败。Gold只在输出固定后由独立本地评价器读取。MRR为冻结评价器的MRR@10。

V3主Pilot完整保留。因完整静态工具封装超过8192输入容量，另注册V4工程控制：A1最多10结果、A2每次5结果，重跑全部12例静态方法，共24条件；不重跑A0/Agent，不改原结果、不重置预算。V4是posthoc开发性上下文控制，不能冒充预注册主Pilot。注册文件、源码哈希、逐条件错误和成本均保存。

初始输入完全相同、额外证据上限相同不代表实际获得相同内容或模型计算成本相同。V3静态最多20条、Agent实际最多10条；V4使最大可能条数也为10，实际反馈仍不同。完整消息超限的条件没有模型调用，不能计为LLM语义0分；系统全条件失败保留分母与模型调用后分母分开报告。
