# 固定方法与缺失值规则

记q为冻结GTE余弦，b为B3合法监督logit，I为训练seen掩码；zq、zb分别按训练r0的所有合法分数拟合单一mean/population-SD，最小SD=1e-8。zb在unseen位置完全没有贡献。p=log(1+唯一训练步骤支持)，z(p)按相应候选列标准化。排序同分按父技术ID字典序，完整216项。

| 方法 | 实际公式 | 未见类 |
|---|---|---|
| Z0 / F0 | q | 正常余弦 |
| S0 / F1 | b | 缺分类器，合法类后按字典序附加 |
| C0 / P0 | support | 支持0，按字典序并列 |
| C1 / F4 | q−γI | 保留q |
| C2 / F2 | 1/(60+r(q))+λI/(60+r_seen(b)) | 仅GTE排名项 |
| C3 / F3 | zq+λI·zb | 保留zq |
| C4 / F5 | zq+λI·zb−γI | 保留zq |
| C5 / P1 | zq+αz(p_all216) | 训练先验修正，不用保留类别频率 |
| P2 | zb−αz(p_seen) | 与S0相同缺分类器规则 |
| C6_B4/B5 | 旧投影模型完整描述评分 | 正常计算216描述得分 |

C3是C4在γ=0时的嵌套对照，避免把相同公式包装成不同创新。C4是待验证的简单监督残差混合。C5加先验检验频率增益，P2减频率偏置检验监督头对先验的依赖；方向先冻结。C0的字典序tie是无信息固定规则，报告零支持类偶然命中不能解释为语义理解。

RRF常数60依据[Cormack等原论文](https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf)；这里只对监督有定义的seen列表添加贡献。Seen校准与权衡是已有广义零样本研究问题，见[Chao等2016](https://arxiv.org/abs/1605.04253)。本轮是日志/多标签/固定候选开发评价的具体应用，不宣称新算法。
