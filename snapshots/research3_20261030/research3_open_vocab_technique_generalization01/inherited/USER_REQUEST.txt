# 七、第二阶段：建立简单而强的监督—零样本融合基线

本轮首先研究成熟、低复杂度的方法。

不要直接设计新的神经网络。

## F0：Frozen GTE

全部216项技术使用冻结语义相似度。

无监督类别修正。

## F1：B3 Supervised Only

继续使用已完成的B3分类器。

训练未见技术保持无监督分类器状态。

必须保留它作为总体已见技术能力的强基线。

## F2：简单排序融合

将冻结GTE排序与B3监督排序组合。

建议使用：

`Reciprocal Rank Fusion`

但必须明确：

B3只在训练已见类别上有合法监督排名。

对于没有监督分类器的技术，不得假装其B3排名与已见技术具有相同含义。

可以采用：

冻结GTE全类别基础排序，加上训练已见类别的B3排名贡献。

必须给出准确公式及缺失监督分数处理规则。

## F3：标准化分数融合

比较：

冻结GTE分数。

与：

经过合法归一化的B3分数。

不得直接将不同尺度的cosine和logit相加。

标准化参数只能来自合法训练或内部验证数据。

## F4：Seen-Class Bias Calibration

针对训练已见技术的预测偏置进行校准。

例如：

\[
s_{\mathrm{cal}}(x,t)
=
s_0(x,t)
-
\gamma\mathbb I[t\in\mathcal T_{\mathrm{seen}}]
\]

其中：

- \(s_0\)为冻结GTE分数；
- \(\gamma\)为类别偏置；
- 类别已见状态只来自训练集。

这是一项标准校准对照。

不属于本研究独立创新。

## F5：监督残差评分

建议建立：

\[
s_{\mathrm{hybrid}}(x,t)
=
z_{\mathrm{GTE}}(x,t)
+
\lambda
\mathbb I[t\in\mathcal T_{\mathrm{seen}}]
z_{\mathrm{B3}}(x,t)
-
\gamma\mathbb I[t\in\mathcal T_{\mathrm{seen}}]
\]

其中：

- \(z_{\mathrm{GTE}}\)为规范化的冻结GTE分数；
- \(z_{\mathrm{B3}}\)为规范化后的合法监督分数；
- \(\lambda\)表示监督修正强度；
- \(\gamma\)表示已见类偏置校准；
- 未见技术保留冻结GTE基础分数。

必须明确：

这是一个待验证的简单混合基线。

**不能因为它具有数学公式，就称为新的知识约束算法。**
