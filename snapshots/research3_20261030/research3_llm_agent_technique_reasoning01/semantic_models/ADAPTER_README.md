# Model adapter status

All statuses: **NOT_MODEL_INFERENCE**. No weight loading tests were attempted. There is no admitted model manifest. GTE embedding / Qwen embedding / GTE reranker implementations are prepared but **untested against weights**. BGE-M3, Qwen reranker and Jina remain **INTERFACE_PENDING**, not completed model implementations. No environments were created for unadmitted models.

Local manifest must explicitly have ADMITTED, exact model ID, immutable revision, license, APPROVED license_review, local_path, audited weights/tokenizer lists (`file`, `sha256`), environment_python and LOCAL_CPU_INFERENCE_APPROVED runtime_authorization. The asset audit owns approval. No adapter grants itself permission. Hashes are checked before importing model libraries; loaders use local_files_only=True / trust_remote_code=False and CPU. Missing dependency is a blocker, never an automatic install. Resource suitability must be checked before changing admission. Each admitted model must use its own audited environment.

GTE uses first-token CLS and L2 normalization; Qwen uses instruction-prefixed queries and last non-padding token, L2 normalization. These choices follow the model-specific [GTE model card](https://huggingface.co/Alibaba-NLP/gte-modernbert-base) and [Qwen embedding model card](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B). Prepared GTE reranker returns scalar logits; monotonic sigmoid would preserve ranking, as described by the [GTE reranker card](https://huggingface.co/Alibaba-NLP/gte-reranker-modernbert-base). Qwen's [reranker card](https://huggingface.co/Qwen/Qwen3-Reranker-0.6B) uses causal no/yes scoring, so it is blocked pending exact-template implementation. [BGE-M3](https://huggingface.co/BAAI/bge-m3) supports three distinct modes via FlagEmbedding; none is claimed implemented here. Official documentation was read without weight downloads.

Run from this root with PYTHONPATH pointing here. `python3 semantic_models/input_views.py` builds the three sampled datasets. Prediction records alone are consumed; references never enter adapter inputs. `rebuild_with_tokenizer(record, tokenizer, budget)` creates common actual-tokenizer log views after admission; callers must reserve instruction, knowledge, pair and special-token overhead. Main proxy artifacts are preparatory only. When comparing models, freeze the intersection of selected observations under every admitted tokenizer budget, then regenerate all views; one-model independently truncated views cannot establish cross-model fair-budget comparisons.

`rebuild_with_tokenizers(record, {audited_model_revision: tokenizer}, budget=2048)` explicitly enforces a shared observation selection under every admitted tokenizer and reports each model’s actual counts. This function is prepared, not tested with real tokenizers.
